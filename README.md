# Quick Sort in C

## Description

This program sorts an array in ascending order using the Quick Sort algorithm.

Quick Sort selects a pivot element and partitions the array into smaller and larger elements. It then recursively sorts both parts.

## Example

### Input

```text
45 12 78 34 9 56 23
```

### Output

```text
9 12 23 34 45 56 78
```
